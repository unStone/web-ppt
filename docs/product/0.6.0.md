# 0.6.0 产品需求文档（PRD）

> 状态：待评审。范围依据 [roadmap §4](../roadmap.md#4-演进路线) 的 0.6.0 行；单票技术细节以票据为准，本文不复述。

## 1. 目标定义

0.6.0 是「下一阶段收口 + Agent 第一批」：把已发布到 `@next` 的实验性能力补齐验收证据后转正，并交付 Agent 读写接口的第一块地基。

| 使用者 | 问题 | 0.6.0 交付后的可见结果 |
|---|---|---|
| 交付型用户（导出 PDF 存档 / 打印） | 图片页面 PDF 文字不可选、放大失真 | 矢量 PDF 转为正式入口：可搜索文字 + 矢量图形，独立读取器可核对 |
| 交付型用户（导出视频） | 导出视频无声；页面里嵌入的视频只剩海报 | 音轨补齐验收证据；内嵌视频逐帧合成进导出时间轴 |
| 企业模板用户（PPT 里嵌 Office 文档） | 嵌入的 DOCX / XLSX 只能整体移动，改不了内容 | OLE 深度编辑在官网编辑器有入口（SDK 已随 0.5.0 发布） |
| AI Agent 开发者（Claude / Codex / 自动化管线） | 读懂 / 检查 / 渲染 `.pptx` 依赖解压改 XML 与 LibreOffice，慢且易产出坏文件 | Node 环境无浏览器、无 Office 直接得到与浏览器一致的 SVG；配 PNG 光栅化注入 |

成功标准：[roadmap §7.1 的 0.6.0 发布检查项](../roadmap.md#710-下一阶段收口--agent-第一批)全部满足——票据关闭、四门禁与 master CI 绿、beta 反馈周期、Windows 真机（或用户明确豁免并记录）、八包 `latest` 一致。

## 2. 用户流程

每项能力的入口、主流程与失败路径：

| 能力 | 入口 | 主流程 | 失败 / 边界 |
|---|---|---|---|
| 矢量 PDF | 官网导出菜单 + SDK 按需入口 | 导出 → 得到可搜索 PDF → 独立读取器选择 / 复制文字 | 缺字体 / 复杂特效局部栅格化并给出有对象定位的回退说明 |
| 视频音轨 | WebM 导出（现有入口） | 含音频的文稿导出 → 声画同轴的 WebM（Opus） | 编码器不支持时明确拒绝；两路混音 / 循环 / 跨页语义缺失则列为拒绝项 |
| 内嵌视频合成 | WebM 导出（现有入口） | 含嵌入视频的页面导出 → 视频内容逐帧出现在导出结果里 | 不可解码容器 / 编码组合、外链不可读字节时明确拒绝，海报仅作显式选项 |
| OLE 深度编辑 | 官网编辑器嵌入对象面板（新入口） | 双击嵌入的 DOCX / XLSX → 改文字 / 单元格 → 原生保存重开内容保留 | 域、内容控件、图形、修订维持整段不可编辑的既有拒绝 |
| Node 渲染 | `@web-ppt/core` Node API（新） | 注入测字与光栅化 → 得到 SVG / PNG → 与浏览器指纹一致 | 未注入测字 / 光栅化时稳定 reason，不退回估算宽度 |

## 3. 功能清单与边界

| 项 | 票据 | 0.6.0 剩余 | 不做什么 |
|---|---|---|---|
| 矢量 PDF 转正 | [005](../wayfinder/ppt-portability-fidelity/tickets/005-vector-pdf.md) | 透明文字渐变、色彩空间与图片范围、字体资源边界、值域审计、多阅读器对照；完成后去掉实验性标记 | 不合并 HTML 与原生文字两条渲染路径 |
| 视频音轨证据 | [006](../wayfinder/ppt-portability-fidelity/tickets/006-video-audio-track.md) | FFmpeg 实测音画同步、两路混音 / 循环 / 跨页、取消与背压证据 | 不用实时录屏替代固定时间轴 |
| 内嵌视频合成 | [007](../wayfinder/ppt-portability-fidelity/tickets/007-video-media-composition.md) | 有界解封装与关键帧定位、元素裁剪 / 透明度 / 层叠、循环与跨页策略、长视频内存边界、失败样本 | 不支持一切容器；播放可用不等于导出可解码 |
| OLE 官网入口 | [014](../wayfinder/ppt-portability-fidelity/tickets/014-ole-docx-runs-tables.md) / [015](../wayfinder/ppt-portability-fidelity/tickets/015-ole-xlsx-styles-richtext.md) | 官网嵌入对象面板入口与中英文文案；LibreOffice 打开改写后文档的验证 | SDK 能力矩阵外的宿主格式继续拒绝 |
| Node 渲染 | Agent [003](../wayfinder/ppt-agent-interface/tickets/003-node-render.md) | 全部（未开工）：Node 与浏览器 SVG 指纹一致、稳定 reason、LibreOffice 对照、耗时记录 | 光栅化器与字体字节不进依赖，全部宿主注入 |

## 4. 调研结论（引用）

- Web Audio 离线渲染与 WebCodecs 能力检测是音轨与合成的规范依据（[006](../wayfinder/ppt-portability-fidelity/tickets/006-video-audio-track.md) 技术方案节）。
- Agent 面的行业现状与本仓库定位见 [AI 与演示文稿调研](../research/ai-presentation-landscape.md)：仓库只提供确定性能力，不内置模型。
