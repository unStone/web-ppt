# Agent 任务评测集

评测提交结果自动附带 lint 对 Agent 编辑成功率的影响。两组运行相同版本的生产 MCP 服务、工具 Schema、输入、提示、真实字体与预算，仅在无反馈组移除成功编辑、撤销和重做结果中的 `value.lint`；显式 `ppt_lint` 保留。

## 数据与接口

| 模块 | 责任与接口 |
|---|---|
| `tooling/agent-eval/tasks.mjs` | `TASKS`、`getTask(id)`、`createTaskPrompt(id,paths)`；版本化任务定义、用户提示、预期标题和受控字体 |
| `fixtures.mjs` | `buildFixture(taskId)`、`buildReferenceSolution(taskId)` 返回确定性 PPTX 字节；基于既有 OOXML 固件工具生成 |
| `runtime.mjs` | 真实 HarfBuzz 测量、字体库存和 Node SVG/PNG；仅受控实色背景，复杂对比度采样、缺字或缺依赖显式失败 |
| `judge.mjs` | `judgeTask({taskId,inputBytes,outputBytes})` 返回 `{taskId,pass,failures,description,lint}`；不调用模型 |
| `host.mjs` | 生产 `createAgentMcpServer` 加 transport 装饰器；路径限制、预算、原始与交付协议记录 |
| `run.mjs` | 固定 Codex CLI、模型、effort、顺序和预算；启动真实配对、保存全部尝试 |
| `records.mjs` / `rejudge.mjs` | 可移植证据包、一条命令离线重判和完成率、失败分布 |

```mermaid
flowchart LR
  T[任务与确定性固件] --> R[相同 Agent 的两个新会话]
  R --> H[生产 MCP + 私有观察装饰器]
  H --> O[真实保存产物与完整协议]
  O --> J[独立重开与七项检查]
  J --> S[配对结果及失败分布]
```

## 任务与判定条件

八类任务覆盖一个干净对照和七项检查；每个任务都要求改成指定标题并保存，提示中允许修复布局、字体与前景文字颜色。原文和图片内容保留，禁止新增、删除、隐藏对象或改主题、母版、版式；标题占位提示可由指定标题替换。

| 案例 | 输入变化 | 最终必须满足 |
|---|---|---|
| 干净对照 | 无布局问题 | 标题正确、保存重开、其他语义保持 |
| 文字溢出 | 文字框不足 | 完整正文保留，字号不低于 12，全文可容纳 |
| 元素越界 | 对象框越界 | 所有对象回到页面内 |
| 文字遮挡 | 前景实心形状遮挡正文 | 对象仍存在且可见，文字无实际遮挡 |
| 图片比例 | 图框与原图比例不同 | 实际引用的图片字节保持、不裁切、比例正确 |
| 对比度 | 低对比文字 | 前景色可调整，背景与内容保持 |
| 字体缺失 | 未注册的 EA 备用字体声明，Latin 首选字体保持真实可测 | 移除未注册声明，只使用实际注册的受控字体 |
| 占位提示 | 标题仍为提示文字 | 指定标题替换提示，其他内容保持 |

最终判定重新解析真实保存字节，完整七项 lint 的问题和失败都必须为空。保护对象身份、可见性、原文、媒体实际引用和设计资源；不把清空、隐藏或孤立媒体当成完成。判定器用正确参考产物与错误变体自检。

字体测量要求首选 family 为真实注册字体且 HarfBuzz 覆盖全部字形；EA 备用声明仍按真实库存诊断，不把未知备用字体加入库存。缺少正文主字体、斜体或字形时不回退估算。公共复杂背景采样接口暂不能注入真实测量，本评测触发该路径时显式拒绝，不将其计为七项检查完成。

任务数据位于 `tooling/agent-eval/fixtures/`，由 `tooling/make-agent-eval-fixture.mjs` 确定性生成，按固件约定挂入 `npm run fixtures` 并验证字节不变；不混入默认解析样本计数。评测自测与真实模型结果使用独立命令，不作为发布门禁。受控 OFL 字体复用已有清单和许可。

## 私有 host 与记录

host 参数为 `--config <JSON>`，配置含 `version:1`、`condition:with-lint|without-lint`、`inputPath`、`outputPath`、`renderDirectory`、`protocolPath`、`maxCalls`。打开仅允许输入和本次输出；保存仅允许指定输出，渲染仅允许本次目录；规范化真实路径后判断，不跟随越界符号链接。

JSONL 逐条保留原始与交付消息、工具名、调用序号和成功保存文件哈希。无反馈组只移除成功 `ppt_edit/ppt_undo/ppt_redo` 的自动 lint，其他字段、失败原因、显式检查和内部执行保持一致。所有处理器与 Schema 来自公开生产包，不复制编辑语义。

禁止增删、隐藏和替换对象的约束还检查真实成功的工具操作；失败原子批次不视为已经执行。会话隐藏不一定写入文件，因此文件语义判定和操作记录判定分开承担，不能伪造文件不可见的证据。

加载、运行、成功、失败、取消、超时分别落盘；取消或超时时关闭 MCP 与 CLI 子进程，保留已发生的调用和产物。每次运行独立目录，旧文件不得作为新结果；最终文件哈希必须对应真实成功保存。

## 实验与边界

采用一个已登录的 Codex Agent，每类任务先做一对；条件顺序交替平衡，所有会话独立且 ephemeral。固定相同的请求 model、effort、超时和调用数预算；关闭 shell，拒绝权限升级，限制判定器及证据目录读取。仅对本次 `ppt_eval` 的十个工具显式设置 `approval_mode=approve`，其余默认 prompt，整体策略仍为 `never`，不启用危险跳过开关；任何非评测 MCP 调用单独记为协议失败，不宣称所有内建工具都不可见。

记录 CLI、请求模型与可观测的实际模型、effort、工具与 Skill 哈希、实现与输入/输出/字体哈希、原始 JSONL、stderr、退出原因、真实 usage、重开 describe 与完整 lint。CLI 未公开的实际模型字段记为未知。公开证据仅映射宿主绝对路径，不包含认证材料；本机原始文件留在忽略的 `out/agent-eval/`。

默认命令只重判已记录证据，另一个显式命令才调用模型。每次尝试都保留，不挑选重跑成功样本；任务、协议、预算上限与外部基础设施终止分别统计，预算上限须有 runner 计时或 host 调用计数证据。八对只代表受控样本，不用于宣称普遍因果收益，也不成为发布门禁。
