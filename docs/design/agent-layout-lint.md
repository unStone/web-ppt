# Agent 布局检查

按 002 的七项检查实现 `@web-ppt/edit-core/lint`。报告只提供可定位的观察结果，编辑仍使用已有命令；当前投影、稳定 ID 与组合几何沿用 describe。

| 决策 | 契约 |
|---|---|
| 读取 | 调用时捕获只读投影、资源及来源信息；异步操作使用该快照，宿主以 AbortSignal 取消已过期的检查 |
| 测字 | 必须注入真实 TextMeasure；现有 Font Provider 可用同步的文字预测量辅助函数准备字宽。浏览器使用 Canvas，Node 不回退到估算 |
| 来源 | 字体库存显式给出 available/embedded；提示文字从保留型 XML 读取，可由宿主补充；图片复用 sourceAsset/readImageMetadata，Data URI 交标准 fetch，外链元数据由宿主提供 |
| 颜色 | 复用标准颜色解析库，按 W3C sRGB 亮度公式计算；普通/大字按 AA 比较，比较前不四舍五入。复杂填充由宿主提供颜色配对，缺少必需数据即给稳定错误，不能假装背景为白色 |
| 几何 | 越界与重叠复用页面外框；空间索引避免稀疏页面逐元素全配对。同一普通组合的成员不互报，背景/装饰按可解释规则排除 |
| 图片 | 比较未旋转渲染帧与原图可见裁剪区域的宽高比，旋转不算拉伸，裁剪后仍拉伸则报告 |
| 结果 | 七个稳定 reason、页/元素 ID、外框和实际阈值；结果顺序固定。任何必需依赖失败或取消时拒绝整个调用，不交付半份成功结果 |
| 生命周期 | 加载由 Promise/进度表达；成功只交付报告；错误带定位；AbortSignal 关闭等待；宿主在编辑世代变化时取消旧任务，异步回调不写入文档 |
| 成本 | 独立构建，默认 core/edit-core 闭包不引入 lint；颜色与空间索引依赖只进入该按需入口 |

| 依赖顺序 | 验收 |
|---|---|
| 修复验证基础 | 编辑基准统一源码运行时；无 dist 的真实建模、恢复与保存回归先失败后通过 |
| 度量与样本 | 确定性正反例；先输出全固件原始几何/排版统计，逐条复核后确定容差、重叠与变形阈值 |
| 检查与 API | 七项正反例、组合/表格/变换/裁剪、缺依赖、取消、失败原子性与文档不变 |
| 环境与发布 | 浏览器真实 Canvas 观测、Node 注入测量与真实 Font Provider；全部固件、跨进程确定性、生成 Schema、外部类型调用与默认入口字节审计 |
| 全仓 | check → test → build → verify；按实测同步数字和票据 |

对比度标准原文已完整读取：[W3C SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。未指定画布背景时采用该定义中的白色；宿主可提供实际画布颜色。重叠与图片变形的默认阈值由本轮固件统计决定，不以预设阈值筛掉候选。
