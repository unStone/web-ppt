# 模板填充生成

执行范围为 [Agent 007](../wayfinder/ppt-agent-interface/tickets/007-template-fill.md)：接收模板与结构化内容大纲，确定性地产出保留主题、母版和版式的原生可编辑 PPTX。内容由调用方提供，生成器不调用模型或网络。

## 入口与原子性

| 决策 | 约束 |
|---|---|
| 独立入口 | `@web-ppt/edit-core/fill`，大纲 Schema 从 TypeScript 生成，校验器无 Ajv 运行时依赖 |
| 模板输入 | 内置模板标识或调用方提供的 `.pptx/.potx` 字节；格式由既有魔数解析路径识别 |
| 输入保护 | 完整校验大纲后，在生成器私有的 EditDoc/Editor 中修改；失败释放私有资源，调用者模板字节不变 |
| 角色匹配 | 使用现有占位符身份、版式来源和几何；角色不足返回带页码和字段的稳定 reason，不按名称猜测或拉伸替代 |
| 文字 | 现有 EditText、段落属性及 normAutofit，保留槽位尺寸和模板默认样式；不能把 FitTextShape 当缩字命令 |
| 图片 | 原生 AddImage/ReplaceImage 和 crop；按 contain/cover 保持比例 |
| 图表 | 在私有生成包中用现有 OPC/XML 写入原生图表与工作簿，再解析取得现有图表编辑身份；不能将图表绘成普通形状代替 |
| 保存与身份 | 保存后重新解析最终字节并使用固定 idPrefix 返回 describe；调用者用相同 prefix 重开，逐字段比较真实最终身份 |

```mermaid
flowchart LR
  O[大纲 JSON] --> V[Schema 与跨字段校验]
  T[模板字节或内置标识] --> P[私有解析与 EditDoc]
  V --> M[按角色选择版式]
  P --> M
  M --> E[新页与原生命令]
  E --> L[真实测量与布局检查]
  L --> S[保存并规范化重开]
  S --> R[字节、describe 与布局报告]
```

## 资源与验收

| 维度 | 验证 |
|---|---|
| 资源作用域 | 私有来源文稿、图表种子与最终规范化文稿分别持有和释放；输入 bytes 不承担资源生命周期 |
| 加载/取消/失败 | 每个异步边界检查信号；没有部分成功文件；错误包含页码、字段与原因 |
| 功能 | 标题、副标题、分级正文、双栏、图片及类别/XY 图表；三套内置模板和一份来源可追溯的外部模板 |
| 原子拒绝 | 未知页类型、图片缺失/格式错误、数据长度不符及无匹配版式 |
| 原生与往返 | 图片字节、图表数据/工作簿/关系、主题与母版保留；最终 describe 与重开一致；LibreOffice 与独立读取器打开 |
| 确定性 | 两个独立进程比较完整 PPTX、最终 describe 和两条 SVG 渲染路径 |
| 成本与门禁 | 默认发布入口静态闭包逐字节不变，独立入口实测；依次通过 check、完整 test、build、verify |

用户明确允许调整生成副本的模板设计，要求全部检查零问题。实现先修复设计几何和字体，再填充内容；最终执行完整检查和可验证修复，重新保存并规范化重开后再次检查。不能通过删除诊断或降低阈值获得零问题，无法可靠修复时明确拒绝。
