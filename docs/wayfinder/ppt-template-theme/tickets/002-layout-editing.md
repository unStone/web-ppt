## Question

`EditDoc.layouts` 目前只是已求值的只读新增页目录，继承节点在普通页面中被标成 `editable: none`。如何把每个版式
建模为拥有稳定元素身份、来源与稀疏覆盖的设计画布，并复用现有元素树、变换、格式、文字、插入与背景/切换命令，
而不把 Layout 冒充 Slide 或复制一套平行命令系统？

公开 seam 应以显式的设计目标打开/查询画布，命令和 Patch 仍是纯数据，普通页面编辑器不能越权修改继承节点。
版式画布支持版式自有图形与占位符的移动、尺寸、层级、文字样式、添加/删除对象、背景和切换效果；页面专属的
备注、隐藏、动画与页序命令必须被类型和运行时共同拒绝。占位符的 type / idx 是继承地址，普通格式编辑不得
悄悄改变它们。

版式变化只失效引用它的页面，并反向运行既有 placeholder-match：仍可匹配的页面占位符保持逻辑身份和直接覆盖，
失去宿主的占位符按既有安全降级固定必要外观，新增宿主进入未绑定提示面；页面换版式、新增/删除页后反向索引
继续正确。补丁保存只修改 layout part 及真实新增资源关系，生成保存物化有效版式；撤销重做、恢复、字段级协同
和跨视图订阅都从同一设计画布 seam 观察。

新增含共享版式、多母版、占位符断开/重绑、母版图形屏蔽和版式背景的确定性固件；用独立进程指纹、LibreOffice
几何/像素 oracle、真实 Chrome 多页传播与 DOM 身份预算证明即时投影等于保存重开。公开 adapter 与文档可发现，
默认查看路径零新增编辑状态，最终四段仓库门禁全绿。
