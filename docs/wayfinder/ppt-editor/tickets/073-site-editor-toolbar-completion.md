## Question

包里已发布的编辑 seam，[editor.html](../../../../packages/site/editor.html) 只暴露了一小部分
（view/edit、撤销重做、插入形状/图片/表格、动画播放、缩放、保存）。如何把其余能力接进产品层，
让编辑页成为能力的完整展示面，而不把产品状态塞回无框架包？

待接线清单（seam 均已在 `@web-ppt/editor` adapter 发布）：

| 能力 | seam 来源 |
|---|---|
| 文字：加粗/斜体/下划线、字号、颜色、对齐 | 票据 031/032 工具栏 seam |
| 形状：填充 / 描边 / 效果面板 | 票据 047/048 |
| 图片：替换 / 裁剪入口 | 票据 049 |
| 超链接编辑 | 票据 050 |
| 页面：背景、隐藏、版式切换、复制/删除/拖动排序 | 票据 044–046、051–053 |
| 备注编辑面板 | 票据 054 |
| 查找替换 UI（Ctrl+F/H 已可用，无可见入口） | 票据 060 |
| 格式刷按钮（单次/连续） | 票据 059 |
| 切换效果选择器 | 票据 061 |
| 元素动画时间线编辑（当前只有播放） | 票据 062 |
| 自动保存开关与恢复提示 | 票据 057 |

要求：工具栏按选区上下文分组显示；1050px / 680px 响应式断点沿用票据 063 的布局策略；
不新增框架依赖；每个面板只调用公开 seam，不 reach 进内部状态。

验收：每项能力在真实浏览器走通「操作 → 撤销 → 保存 → 重新打开验证」；390×844 与 1280×720 截图检查；
零 console warning；生产构建体积增量在票据内如实记录；全部门禁绿。
