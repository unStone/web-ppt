## Question

如何让用户从当前选区取得格式，一次点击或连续点击把外观复制到其它对象/文字，同时让 headless 命令、画布、历史、保存、恢复、多视图和 React/Vue 宿主共享同一真相，并保证格式刷绝不复制几何、内容、链接、裁剪、名称或 OOXML 身份？

`ApplyFormat` 必须是严格纯 JSON 命令，显式携带 `from`、`to` 和非空无重复 `mask`。对象掩码覆盖 `fill`、`stroke`、`effects`：复制来源的**有效值**并在目标形成直接覆盖，使继承来源不同的对象仍获得相同视觉；矢量填充只允许 shape，描边允许 shape/image，效果允许 shape/image/group，图片填充属于媒体内容且不由格式刷复制。空填充、无描边与空效果都是明确格式，不能被误当成“恢复目标来源”。任一掩码不兼容、目标或祖先锁定、只读文档、不可写目标或非法动态输入都必须在落模前原子拒绝。

文字掩码覆盖 `run`、`paragraph`、`body`，支持形状和表格单元格文本目标。来源/目标可显式给出范围；省略范围表示整个文本体。来源范围内对应属性必须一致，混合格式不得静默取第一个值；文字内容、段落/run 边界和目标中未列入掩码的格式保持不变。文字格式和对象格式可在一个命令中组合成单一撤销单元，撤销/重做、崩溃恢复和保存重开必须精确。

`@web-ppt/editor` 提供会话级格式刷控制器：从当前单一元素或文字选区启用，一次模式成功应用后自动退出，连续模式保持来源并可跨页/多视图继续；`Escape`、显式取消、切换 view 模式、来源删除或会话销毁立即退出。格式刷激活时普通点击先应用再选中目标，失败时保留模式并通过统一错误 seam 报告；锁定/隐藏对象不能成为目标。宿主用数据属性自定义光标/按钮状态，adapter 暴露启用、取消与只读状态，React/Vue 不复制状态机。

确定性固件覆盖跨页不同继承、shape/image/group、无填充/无描边/空效果、多 run/段落、表格单元格和未知相邻 XML。Node 契约从公开命令验证严格性、原子性、单历史单元、恢复、最小 XML 与连续保存；真实 Chromium 验证一次/连续模式、Escape、失败保留、多视图/adapter 生命周期和 DOM 增量边界。60 元素页从点击到完整反馈 p95 不超过 16ms；默认预览、只读解析和框架适配体积门禁继续通过。保存产物进入统一 Office 清单并由 LibreOffice 实际打开；Windows PowerPoint 真机仍服从任务“证明 M1 最小写回与真实软件兼容”的证据契约。

## Resolution

- `ApplyFormat` 以严格纯 JSON 命令贯通对象与文字格式复制：运行时共享非空无重复 mask schema，物化来源有效值为目标直接格式，支持显式空格式、范围文字和表格单元格；图片填充不进入格式刷，几何、内容、链接、裁剪、名称和 OOXML 身份保持不变。对象与文字组合仍只形成一个历史单元，并通过撤销、重做、恢复与连续保存契约。
- 会话级格式刷支持单次/连续、跨页和多视图；点击先应用再选中，失败保留模式，`Escape`、显式取消、切换 view、来源删除和销毁均可靠退出。adapter 暴露统一动作、状态和数据属性，React/Vue 只消费同一个框架无关控制器。真实 Chromium 60 元素完整反馈 p95 为 0.300ms。
- 确定性固件 `sample-editor-format-painter.pptx` 的 SHA-256 为 `39f586326faf35674fe2abdd558e0d121afba256522ef0dba116680629759253`；保存仅改动两份 slide part，LibreOffice 实际打开并导出 143277 字节 PDF。Windows PowerPoint 真机证据继续由任务 010 管理，不用替代证据冒充。
- 精确运行 `npm run check && npm test && npm run build` 全绿：core 2135、edit-core 812、保存 322、PowerPoint 证据契约 9、editor 331、框架适配 8、63 份固件/190 页/380 对 SVG 等价、metafile 130，七个发布包全部构建成功；规范与需求两路最终审查均为 0 项发现。
