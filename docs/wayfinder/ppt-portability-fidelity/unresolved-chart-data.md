# 旧图表无法恢复时的呈现

旧裸模型缺少原页身份、复制身份冲突或共享覆盖无效时，保留旧数据并明确显示失败状态。完整票据仍以
[共享图表验收](shared-chart-progress.md)为准；本增量的四项全仓验证已顺序通过，整票随后完成了最终成本与视觉验证。

| 入口 | 行为 |
|---|---|
| 数据查询 | `binding.mode = readonly`、`unresolved = true`、具体 `reason`；类别和系列为空，避免来源值被误认为当前数据 |
| 编辑画布 | 投影为 `unsupported` 占位；模型中的原生图表、局部覆盖、时钟与恢复证据保持 |
| 独立图表 XML | `chartProjection()` 抛出原因，调用方不能导出来源缓存作为恢复结果 |
| 编辑及保存 | 原子拒绝；无局部覆盖的首个框架不能使保存跳过仍有旧编辑的副本 |
| 产品恢复 | Cordis 打开服务在首次挂载前加载扩展；检查器显示数据保留状态，画布占位支持中英文 |
| 可读取的普通只读图表 | 保留原有预览，不标记为未恢复 |

来源投影在局部扩展前执行，即使当前框架没有局部字段，其他框架的失败也会影响它。
迁移与诊断共用同一身份校验，诊断不调用协同时钟裁决器，不安装地址。诊断缓存按来源字节及内容摘要失效，
容器原地修改仍能被识别；缓存只保留字符串，释放旧模型不依赖下一次读取。

| 验证 | 当前证据 |
|---|---|
| 原页记录及日志缺失 | `bare-model` 用既有确定性 PPTX 生成旧裸模型，检查查询、占位、原数据保留及无关图表 |
| 身份碰撞 | `identity-collision` 与 `identity-copy-only` 同时覆盖原件有/无局部覆盖 |
| 无时钟的矛盾字段 | `conflicting` 验证整组未恢复和保存拒绝 |
| 无效共享数据 | 既有缓存边界用例新增未恢复状态、空查询和占位断言 |
| 真实产品入口 | `out/chart-shared/unresolved-browser-v4.log`：原生 IndexedDB、首屏占位、中英文检查器、保存拒绝后记录保留和显式丢弃均通过；后续完整共享图表流程通过 |
| 提示生命周期 | `test-site-chart-recovery-labels.mjs`：加载失败后重试、重绘后重新翻译、普通文稿文字不被修改、卸载后不写 DOM |
| 全仓门禁 | `out/chart-shared/unresolved-final-gates-v2.log`：check → test → build → verify 终态为 0，542 项一致性检查通过；源码与发布包各 2,244 项共享断言、45 组迁移契约 |

首轮全仓验证停在浏览器用例残留的同源恢复记录，构建及 verify 未执行。修正用例清理时又发现第二次打开
被未保存确认对话框阻塞；现沿用已有测试的确认处理，先证明失败保存未删除记录，再通过显式丢弃归还测试数据。
两次失败保留于 `unresolved-final-gates.log` 和 `unresolved-browser-v3.log`，不计为通过。

失败诊断仍须按值读取相关覆盖，不能把它宣称为 O(1)。本机 10/30/60/100 个冲突框架热查询约
4/19/42/95 ms；每帧重复完整规划时为 14/70/199/537 ms。两组为诊断对照，不替代正式浏览器成本测量。
