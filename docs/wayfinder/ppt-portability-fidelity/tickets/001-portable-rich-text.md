## Question

如何让无可补丁原包的公式、艺术字与高级文字效果保持原生语义，通过生成保存和直接复制进入目标 PPTX？

## 范围与路径

| 步骤 | 工作 |
|---|---|
| 复现 | 覆盖 `generate/materialize.ts` 对 warp、math、outline、gradient、underlineColor、shadow 的拒绝；区分真正无来源和来源已由会话保留 |
| 保留语义 | 为生成所需的文字填充/效果补结构化信息；复用现有 MathNode、TextWarp，区分有效外观与编辑来源 |
| 原生写入 | 实现支持节点的 OMML、DrawingML 艺术字与文字效果序列化；已有 CSS 字段保持兼容，未知表达不猜测 |
| 统一流转 | 生成保存与 `copyPortableElements` 共用物化器及能力校验，保留关系闭包、稳定身份和祖先变换 |
| 集成 | 公开入口与官网复制操作复用同一能力；不增加未要求的公式可视编辑器或通用 CSS 解析器 |

## 验收

- 至少覆盖嵌套分式/根式/脚标、艺术字调整值、描边/渐变/阴影组合、独立下划线颜色、表格内公式和跨文稿资源。
- 无来源 → 复制/生成保存 → 目标继续编辑 → 保存重开，语义保持；有来源文稿的补丁保存无回归。
- 无法恢复的原生信息带对象定位明确拒绝；批量复制中一个对象失败不能修改源稿或目标稿。
- 原生 XML 与独立 LibreOffice 对照共同验证，适用的历史/恢复/协同与[共同完成条件](../plan.md#共同完成条件)通过。

## Answer

2026-09-07 完成。[支持矩阵与 API](../../../portable-rich-text.md)明确区分可生成的原生语义与无法恢复的信息。

- 保留精确线性渐变、外阴影和解析损失标记；从统一模型生成 OMML、艺术字与文字效果。
- 生成保存和直接复制共用物化器，支持表格内公式、图片项目符号资源、历史、冷恢复及外部补丁。
- 识别真实 `a14:m` 包装；补丁保存不丢公式。清除格式和纯色覆盖同步更新结构化属性，避免旧效果复活。
- 隐藏公式参数、未知命名空间/属性、无法重建的效果及艺术字表达式带元素身份拒绝，批量失败不修改来源。

| 验收 | 实测结果 |
