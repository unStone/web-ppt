## Question

如何把 004 已证明可行的字体字节、定位字形和原文区间能力接成稳定的按需 SDK，并随 Cordis 文稿生命周期释放资源？

## 范围与决策

| 层 | 实现范围 |
|---|---|
| SDK | 在 `@web-ppt/fonts` 增加独立按需入口，接口从 004 草案收敛为[正式类型](../../../../packages/fonts/src/glyphs/types.ts)；不新建发布包，不静态引入 core 主入口 |
| 整形器 | 通过 loader 注入可选 HarfBuzz 适配；主入口不依赖 WASM/字体字节。宿主可替换适配，不把字体库暴露为 API 类型 |
| 首版字体 | 静态单 face TTF/glyf；EOT 经已有 hook 解码后，须再次验证 sfnt、外层及内层嵌入限制；不自动视 WOFF2/CFF 为 TTF |
| 首版文字 | 横排 LTR Latin、汉字及标点，明确脚本/方向/字体分段；支持实测连字、组合音标和 UTF-16 区间，缺字按簇报告 |
| 字体来源 | 显式字节、文稿合法嵌入字节和显式替换字节；家族、字重、斜体精确解析，不静默伪造字体或绕过缺字 |
| 资源 | 文稿独占 Worker；取消加载/整形、关闭、重复关闭、待完成请求、打开失败和迟到结果均可收口。HarfBuzz 1.6.1 无公开立即销毁 API，不能依赖最终 GC 等同于关闭 |
| 产品 | Cordis 文稿服务拥有 provider，插件退出时销毁；SDK 不依赖 Cordis。官网中英文状态覆盖加载、缺字体、缺字与不支持原因 |

## 必须补齐的工程条件

- 原型仅粗查表目录，正式实现须验证输入边界、字体大小/字形数量预算、cmap/loca/glyf/table 范围与解码失败；资源耗尽可取消。
- 按 OS/2 版本解释 `fsType`，检查 EOT 外层限制、独立许可依据与使用目的。Preview & Print 不开放编辑，No Subsetting 走完整字体嵌入，Bitmap Only 不输出轮廓；不修改源权限标志。
- 原文簇与定位字形分开表达，保留同 GID 不同原文（`ffi`／`ﬃ`）及组合字形。复杂重排、双向/竖排、可变字体、TTC、CFF、彩色字体及 WOFF 解压暂不支持，返回定位原因。
- 接入两条既有文字路径的排版依据；不要顺带另造断行器或改成单一路径。PDF 编码和 ToUnicode 分配属于 005，艺术字变形属于对应渲染票。
- 样本生成依赖保持开发用途；吸收原型的有效决定和确定性样本后删除 `packages/fonts/prototype` 临时实现及其私有依赖。

## 验收

| 维度 | 证据 |
|---|---|
| API | 独立入口类型、Worker 无 DOM、主入口零增量依赖、缺字和字体权限可定位；消费者无需直接操作 HarfBuzz 对象 |
| 格式/文字 | 确定性固件覆盖字体来源/字重/斜体/组合音标/连字/缺字/不支持容器；真实 MTX 另以可追溯语料验证 |
| 一致性 | 字节 hash、字形 ID、原文簇、字宽/偏移和轮廓同源；MuPDF/其他独立读取器复核嵌入证明，不仅自己读自己 |
| 生命周期 | 反复打开/关闭、导出取消、文稿切换与迟到请求；Worker 退出、资源持有归零，无跨文稿污染 |
| 成本 | 首次及重复加载、代表性完整中文字体和长文本、并发/取消压力；区分 JS 堆、WASM 容量、持有字节与 RSS，不把 004 的小样本数字外推到大文稿 |
| 完成条件 | [共同完成条件](../plan.md#共同完成条件)及四项仓库门禁；005 在本票关闭前保持阻塞 |

依据：[004 原型结论](../font-glyph-prototype.md)。本票不包含正式矢量 PDF、任意复杂语言整形或字体格式全覆盖。

正式接口、支持范围及完整证据见[实现进度](../font-glyph-implementation.md)。

## Answer

正式字体 Provider 与 Cordis 文稿字体服务已验收；SDK 保持独立按需，产品负责字体、Worker、FontFace 与 URL 的生命周期。

| 验收项 | 结果 |
|---|---|
| API / 发布 | 四个可选入口与默认入口分离；真实 tarball 的独立消费者、HarfBuzz 注入消费者均通过严格类型检查，未携带字体 / WASM / Cordis |
| 格式 / 文字 | 静态 TTF/glyf、合规 EOT、Latin/Han LTR、字形定位与 UTF-16 簇；权限、缺字及不支持原因明确。五份真实 MTX 解码结果含非法 cmap，被注册校验拒绝；另一份字重 900 不进入仅 400/700 的浏览器绑定 |
| 独立证据 | 当前正式 API 重新生成四行证明；MuPDF 两种文本映射精确提取，FontTools 独立比对 36 个轮廓，嵌入字节及 No Subsetting 完整性通过 |
| 生命周期 / 产品 | 源码和 dist 三轮文稿切换、取消 / 迟到结果、IME、本机替换、失败释放、导出取消通过；三张正式站点页面完整中英文工作流通过。运行时字体不进入历史或 PPTX |
| 成本 / 原型 | 完整中文字体 10.6 MB / 31,036 字形以及长文本并发 / 取消实测完成；统计口径及未测 RSS 明示。确定性样本和许可已迁移，原型及私有依赖已删除 |
| 门禁 | check、test、build、verify 全部通过；151 份 PPT 固件 / 988 对等价指纹、186 份快照，source / dist 字体合约均通过，原有预算未放宽 |

日志、原始测量、包体积及审查修复见[验收记录](../font-glyph-implementation.md)，使用方式见[字体指南](../../../font-glyphs.md)。011 关闭后，005 的字体前置已满足；矢量 PDF 仍由 005 单独实现和验收。
