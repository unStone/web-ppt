## Question

如何直接导出包含真实文字和矢量图形的 PDF，同时明确字体缺失与复杂特效的降级范围？

## 范围与路径

- 前置[字体正式实现](011-font-glyph-implementation.md)必须完成并提供支持矩阵；004 原型只证明路线成立，字体家族名称不能满足准确嵌入需求。
- 复用原生文字路径的排版依据，在独立 PDF 入口写文字、路径、填充、描边、变换与裁剪；避免维护另一套断行规则。
- 以按需适配或输出模块承担 PDF 格式知识，`render/` 不感知 PDF；不合并 HTML 与原生文字两条现有路径。
- 普通文字提供字体嵌入、字形定位和 ToUnicode 映射；复杂滤镜或特殊变形只局部栅格化，并返回有对象定位的回退说明。
- 保留既有图片 PDF，支持批注/回复、隐藏页、动画批次、进度和取消；不承诺特殊字形效果仍可原样选择。

## 验收

- Poppler 等独立读取器提取中英文、组合字符与多段落文字，文本内容和阅读顺序可核对。
- 检查普通图形确实是矢量对象，字体资源和映射有效；以独立渲染对照排版、裁剪及局部回退边界。
- 缺字体/缺字、取消、多页输出、重复调用和资源释放可重复验证；满足[共同完成条件](../plan.md#共同完成条件)。

## 进行中
