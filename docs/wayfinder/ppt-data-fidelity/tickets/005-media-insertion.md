## Question

现有解析器能读音视频，编辑器却不能插入。如何新增音频、视频和海报图而不建立第二套媒体资源模型，并保证
保存、复制粘贴、恢复与协同后的文件仍能离线播放？

提供纯数据 `AddMedia` 命令：媒体可来自字节或显式外链，视频必须支持海报图，音频使用确定性内置图标或用户
海报；MIME/扩展名按签名字节与受控表确认，不信任文件名。嵌入资源按内容哈希去重并同时写入 `audio` / `video`
与 `p14:media` 兼容关系，外链永不冒充嵌入。命令复用图片插入的几何、关系闭包、历史和稳定身份，框架适配与
官网只转发同一 seam。

验收覆盖 MP4、WAV、外链、重复字节、替换海报、复制/删除、撤销重做、恢复/协同、补丁/生成保存、离线重开、
真实 Chrome 播放控件和 LibreOffice 无修复打开；恶意 MIME、超限字节与失效 URL 明确拒绝或降级，默认入口无
媒体编码器和示例字节。
