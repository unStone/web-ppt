## 约束与决策

- 新范围取代旧 roadmap 的对应“不做”决策；未知格式必须说明边界并拒绝有损编辑，不以改扩展名或位图替代原生对象。
- 新增实现按需加载，core 仍只依赖 fflate；`render/` 保持格式无关，Worker 与两条文字路径继续保留。
- 原生 PPT 按当前投影生成新文件；不宣称保留未知二进制记录。支持矩阵之外的内容以带页码的 `PptSaveError` 拒绝。
- PDF 采用图片页面；需要可选中文字时仍使用打印 HTML。WebM 无音轨，内嵌媒体必须明确选择静态封面。
- 用户已授权本轮实现、验证和本地提交。Windows PowerPoint 真机按此前要求跳过；宏、AI 生成、模板市场、服务端转换、发布/tag/推送不在本轮范围。

## 本轮收尾与审查

| 发现 | 根因与修复 | 证据 |
|---|---|---|
| 旧 PPT 无写入入口 | 新增持久化对象、主记录、Escher、图片和 Notes 写入器 | 40 项契约、浏览器下载/重开、独立 LibreOffice 重开 |
| 独立入口资源或 hook 不共享 | 图片/PDF/PPT 等通过主包公共资源及渲染 API 访问，避免重复模块的 WeakMap | 独立发布入口交叉验证纳入 `verify` |
| 透视网格半透明共边变深 | 重叠三角形重复合成；纯色表面直接投影轮廓，文字/纹理改用互斥像素遮罩 | 0.5×、1×、2×、4× 内部 alpha 均为 128，无叠色或漏底 |
| 三维轴映射及材质改变深度 | lat/lon/rev 对应 XYZ；材质不影响实际挤出高度 | 33 项契约及 LibreOffice 画面对照；仅更新 showcase 第七页的两条快照 |
| 备注出现多余制表符或整页失败 | 段落制表位误认成字符，且误用了 xml-lite 不支持的 DOM 方法 | 固件同时包含制表位和实际制表符；Node/Worker 路径与原生保存通过 |
| CFB 目录树黑高度不一致 | 平衡树的不完整末层应染红 | 0–31 个流的红黑树路径不变量及独立读取器 |
| 新按需入口令旧测试无法构建 | 根包文件 alias 吞掉子路径 | 从 tsconfig 补齐源码入口，保留独立产物测试的显式映射 |
| 只读图表仍可修改样式 | 样式使用同一工作簿可编辑性判断，API 与界面共同拒绝 | 新增原子拒绝契约与生产页面中英文只读回归 |
| 复制模块加载期间取消打开 | 新异步阶段未复用取消语义 | 在建模前加载，复用现有取消与资源清理路径 |
