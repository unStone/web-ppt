## Question

用户怎样一次性为全部或部分页面打开日期、页码、页脚，并给对象设置单击或悬停时的动作（跳页、结束放映、播放声音）？

## 现状

渲染已能显示日期、页码与页脚域；`SetLink` 支持元素级与 run 级超链接。没有批量页眉页脚命令，悬停动作与“结束放映 / 播放声音”等动作类型没有编辑入口；预设几何已含动作按钮形状。

## 范围

| 部分 | 说明 |
|---|---|
| 页眉页脚 | 按页面、备注与讲义分别开关日期（固定 / 自动更新及格式）、页码、页脚文字、标题页不显示；写入 `p:hf` 与对应占位符 |
| 动作 | `hlinkClick` 与 `hlinkHover`：跳到指定页 / 首页 / 末页 / 上次查看、结束放映、自定义放映、URL、播放声音、单击时突出显示 |
| 动作按钮 | 插入动作按钮时自动带上对应默认动作 |
| 放映 | viewer-core 执行悬停动作与声音 |
| 产品入口 | 页眉页脚对话框与动作设置面板（产品待确认） |

## 完成条件

- 每种动作有固件，放映中行为有浏览器断言；保存重开一致。
- 页眉页脚开关覆盖母版缺少占位符的情况（按版式补占位符）并有测试。

## 参考

上游 `src/api/fn/shape-click-action.ts`（MIT，`18b7e75`）可用于核对动作的 `ppaction://` 写法；上游没有 `p:hf` 页眉页脚编辑，依据 ECMA-376 §19.3.1.25。
