## Question

用户怎样在大纲视图里只看和改文字结构，在备注页视图里按打印效果编辑备注，并在窗口内以阅读视图浏览？

## 现状

官网编辑器只有普通视图（缩略图、画布、属性页签）与放映；没有大纲、备注页与阅读视图。

## 范围

| 视图 | 说明 |
|---|---|
| 大纲视图 | 每页标题与正文层级的文字编辑；Tab / Shift+Tab 调级，回车在标题级新建页；改动经 `EditText` 与 `AddSlide` |
| 备注页视图 | 复用 011 的备注页排版，可直接编辑备注正文 |
| 阅读视图 | 窗口内放映，保留浏览器界面与状态栏 |
| 归属 | 产品层视图插件；编辑全部经现有命令（产品待确认） |

## 完成条件

- 大纲视图的增删页、调级与普通视图实时一致，撤销 / 恢复覆盖。
- 三种视图在桌面与触屏下有浏览器测试。
