## Question

用户怎样把演示文稿打印或导出为讲义（每页多张）、带备注的备注页和纯文字大纲？

## 现状

打印 HTML 按动画批次展开整页幻灯片；PDF（图片与矢量）只输出整页幻灯片。文件中的备注母版与讲义母版不参与排版。

## 范围

| 版式 | 说明 |
|---|---|
| 讲义 | 每页 1、2、3（附横线）、4、6、9 张，横向或纵向排列；使用讲义母版的页眉、页脚、日期与页码 |
| 备注页 | 使用备注母版的幻灯片图像与备注正文占位符排版 |
| 大纲 | 标题与正文层级文字 |
| 选项 | 纸张与方向、彩色 / 灰度 / 黑白、加框、隐藏页、页范围 |
| 输出 | 打印 HTML、图片 PDF 与矢量 PDF 共用同一排版结果 |
| 产品入口 | 打印对话框与预览（产品待确认） |

## 完成条件

- 各版式有确定性固件与快照；矢量 PDF 中备注与大纲文字可搜索。
- 讲义 / 备注母版缺失时按 PowerPoint 默认版式生成，并有测试。

## 参考

上游无讲义排版；版式依据 PresentationML `p:handoutMaster` / `p:notesMaster` 定义。

## 不做

- 浏览器打印对话框之外的打印机控制。
