## Question

用户收到别人修改过的版本时，怎样看到两份文稿逐页、逐元素的差异，并选择接受或拒绝每一处改动？

## 现状

`describe` 能输出带稳定身份的结构化内容；没有两份文稿的差异计算与合并入口。

## 范围

| 部分 | 说明 |
|---|---|
| 配对 | 页面按身份与内容相似度配对（插入、删除、移动）；元素按 `cNvPr` id、名称与几何配对 |
| 差异 | 文字（字符级）、格式、几何、图片字节、表格单元格、备注、版式 |
| 合并 | 每处差异可接受或拒绝，接受即执行对应 `EditDoc` 命令，进入历史 |
| 输出 | 稳定 JSON 差异结果（供 Agent 使用）与产品层审阅面板（产品待确认） |

## 完成条件

- 典型改动集合（增删页、改字、移动、换图、改表）的差异结果确定并有断言。
- 全部接受后的文稿与修改版 describe 一致；全部拒绝后与原版一致。
