## Question

用户选中多个形状后，怎样像 PowerPoint 一样执行结合、组合、拆分、相交、剪除，得到一个可继续编辑的自定义几何形状？

## 现状

已有 `ConvertToCustomGeometry`、顶点编辑与 `custGeom` 写出；没有路径布尔运算。

## 范围

| 部分 | 说明 |
|---|---|
| 运算 | union（结合）、xor（组合）、fragment（拆分）、intersect（相交）、subtract（剪除，以首选对象为被减数） |
| 几何 | 预设形状、自定义几何、文字轮廓之外的线条先求值为路径；曲线保持贝塞尔，不在运算前折线化 |
| 结果 | 生成 `custGeom` 形状，继承首选对象的填充、描边与效果；文字保留在首选对象 |
| 图片参与 | 首选对象是图片时，运算结果作为图片的形状裁剪写出（沿用现有裁进形状的保存路径），图片字节不重新编码 |
| 依赖 | 布尔运算实现位于独立子入口；若采用第三方库，须为 MIT 或同等宽松许可且只进入该子入口 |
| 产品入口 | 形状格式菜单（产品待确认） |

## 完成条件

- 五种运算在重叠、相切、包含、自交、空结果等情形有确定性固件与几何断言。
- 结果保存后 LibreOffice 与 Open XML SDK 校验通过；撤销恢复原对象及其身份。
- 默认闭包体积不变。
