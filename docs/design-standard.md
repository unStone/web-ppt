# 功能设计标准

给新功能设计与评审用。代码怎么分层见 [architecture-rules.md](architecture-rules.md)；命令与门禁见 [AGENTS.md](../AGENTS.md)；测试怎么写见 [testing.md](testing.md)——本文管的是**功能怎么设计**：交互状态、错误与回退、兼容与演进、确定性、验收、资源生命周期。每条规则都附仓库真实踩过的坑作依据，规则本身可判定，评审时逐条对照。

## 1. 交互状态：五态与世代令牌

任何异步操作（打开文件、加载字体、导出、保存）设计时必须同时回答五个状态的各自行为，缺一不可：

| 状态 | 必须明确 | 反面案例（真实踩坑） |
|---|---|---|
| 加载中 | UI 可用性、能否再次发起、进度反馈 | 解析期间按钮不置灰，用户连点三次 |
| 成功 | 结果落在哪、后续链路 | — |
| 失败 | 用户看到什么、资源是否回收、能否重试 | 文件打开失败不删 `?file=`，刷新后撒谎说还在 |
| 取消 | **走回调闭环**，不是移除 UI | 密码框只 `remove()` 会让 `show()` 的 Promise 永远挂死 |
| 过期 | 结果丢弃，不覆盖后来者 | 迟到的 `requestFullscreen` 回调在取消后仍进全屏 |

**世代令牌是过期态的标准实现**：异步开始时取世代，完成时校验世代，不符则丢弃。字体重排的 `ensureFonts`（换文件或翻页即作废）、打开链路的「后一次赢」、Cordis 的过期打开，全是这一条。

状态收尾要连带关联物：换稿后过期备注面板必须收起（只清正文会留「本页无备注」空壳骗人）；`blob:` URL 不能当分享状态残留。

## 2. 错误与回退

| 规则 | 判定 | 依据 |
|---|---|---|
| 回退必须有**稳定 reason code** | 机器可读、支持人员凭它直接定位；产品文案按 code 分类说明原因 | 矢量 PDF 的回退列表按滤镜 / 特殊文字 / 剪裁遮罩 / 复杂填充分类，中英文切换不重跑导出 |
| **禁止静默降级** | 出现以下任一即违规：无 reason、无日志、无能力边界声明 | 图表不兼容转换、缺字体（`face-unavailable`）、支持矩阵外的 `.ppt` 保存，全部显式拒绝 |
| 接口存在 ≠ 支持 | 运行期能力必须前置探测（`isConfigSupported` / 探测 + 回退），探测失败显式报错 | WebCodecs Opus：不能因 `AudioEncoder` 存在就假定可编码；`ctx2d()` 探测结论必须缓存 |
| 能力边界写成矩阵 | 每个按需入口声明支持范围与已知边界，不宣称完整支持 | [chartex-native](api/chartex-native.md) 的开放票据登记模式 |

错误信息本身遵循 fast-fail：写明失败对象、实际状态、预期条件（见 AGENTS 工程约定，这里只补产品面：错误文案随 reason code 走中英文双语，新增 code 必须双端同步）。

## 3. 兼容与演进

| 规则 | 判定 | 依据 |
|---|---|---|
| 新能力**默认关闭时产物逐字节不变** | 关闭态与上一版本对比（快照 / 等价指纹） | 视频音轨：无 `audio` 声明的 WebM 与旧路径字节一致；`WebmWriter` 未声明音频轨时输出不变 |
| 重能力走按需入口 | 默认闭包不增长（verify 的体积门禁守住）；宿主不注入就不付出成本 | chart-ex / emf-plus / three-d / pdf-vector 全部独立入口 |
| 注入点选 hook 还是可选接口 | 体积大且多数用户用不到 → hook（`setChartParser`）；参数化扩展 → 可选接口（provider 的 `outline?`——不提供的宿主上对应功能按稳定 reason 回退，其余不受影响） | 文字渐变垂直轴：无 outline 的自定义 provider 回 `outline-unavailable` |
| 持久化格式带版本 | 恢复帧 / 协同补丁版本化，旧版本走迁移 | `EDITOR_RECOVERY_VERSION` 与恢复迁移 |

## 4. 确定性

| 对象 | 标准 | 依据 |
|---|---|---|
| 固件 | `npm run fixtures` 重跑两次字节一致（CI 强制）；禁止时间戳 / 随机数 | 确定性生成脚本约定 |
| 时间轴 | 离线固定时间轴优先于实时 API——视频导出不受实际耗时影响 | 混音核用纯函数而非 `OfflineAudioContext` 的实时调度语义 |
| 渲染比对 | 同进程不可比（defs id 全局计数器），指纹必须在**独立进程**算 | `tooling/lib/ppt-fingerprint.mjs` |
| 转换样本 | LibreOffice 输出非确定性时按**渲染结果**而非字节比对 | `.ppt` 样本保留策略 |

**可比对性分级**（验收时先声明用哪级）：字节一致 > 归一化快照 > 独立进程指纹 > 像素 MAE 对照（带阈值与已知差异说明，如阅读器插值差异）。

## 5. 验收

| 规则 | 判定 | 依据 |
|---|---|---|
| **方向断言硬，幅值断言如实** | 语义正确性用可判定的方向断言（色相 / 结构 / 序）承担；数值阈值放宽必须登记原因，不硬凑 | 多重文字渐变：分框语义三窗色相断言 + MAE 阈值分级放宽至 2（窄 run 亚像素框差登记在案） |
| 真实现优先 | mock 只在真实边界（外部服务 / 时间 / 随机）且遵循契约；关键路径必须有真实现验收 | 真浏览器（withChartBrowser）、真 ffprobe、真 Cordis 注册/卸载 |
| 规范分歧用**跨实现裁决矩阵** | 至少三个独立实现实测；分歧时不硬凑兼容，按「不可靠不上线」回退并登记候选路径 | PatternMatrix：MuPDF / poppler / CoreGraphics 三实现裁决坐标口径；PDFium 无环境路径如实登记 |
| 变异验证 | 把已修复 bug 改回去必须被抓到 | 测试套件变异记录（AGENTS 已述，此处要求新回归锚点同样自检） |
| 环境缺失降级必须声明 | 跳过的断言打印原因与覆盖边界，「跳过」不冒充「通过」 | 音轨验收：CI 无 ffprobe 时降级字节级断言并打印说明 |
| 数据取证用实测 | 文档数字（断言数 / 体积 / 快照数）改前先跑 `npm run verify` 拿实测 | verify 一致性闸门的存在理由 |

## 6. 资源生命周期

先声明作用域，注册与使用必须在同一作用域：

| 作用域 | 例子 | 踩过的坑 |
|---|---|---|
| 文档级对象 + 页级注册 | PDF 的 Pattern / Shading | 跨页缓存命中跳过本页 `Resources` 注册 → MuPDF 报 cannot find Pattern resource（单页导出不触发，极隐蔽） |
| 会话级 | 编辑会话、字体 Provider / Worker | Cordis disposer 是 thenable，async generator 会先解包导致父作用域并行清理——用同步 effect 收编，逐层等待工具→视图→字体→会话 |
| 隔离上下文 | SVG-as-image、Worker、`blob:` URL | SVG 被 `<img>` 加载拿不到页面字体，必须内联 `@font-face`；`blob:` 加载含 foreignObject 的 SVG 会污染画布，用 `data:`；Worker 无 `DOMParser`，走 `xml-lite` |
| 交付期间 | 保存 / 导出任务 | 文件交付期间停止编辑命令，但触摸缩放与视口尺寸仍须同步（界面不能假死） |

新资源进场时先填这张表；「注册作用域 ≠ 使用作用域」是本仓库真实损失最大的 bug 类型之一。
