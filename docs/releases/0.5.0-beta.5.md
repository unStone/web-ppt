## 接下来按什么顺序做

| 顺序 | 工作 | 收口条件 |
|---|---|---|
| 1 | 005 PDF 产品交互 | 完整中英文加载失败、对象回退说明、隐藏页 / 动画 / 批注选项逐项验收 |
| 2 | 005 格式与成本 | SVG 值域及引用审计、高级文字与 CJK 簇、更多图片 / 效果组合；长文稿耗时和峰值内存、默认入口边界、其他 PDF 阅读器对照 |
| 3 | 005 整体验收 | 更新支持矩阵、逐项审计需求、独立审查和最终四项门禁；现有图案栅格差异仍保留记录 |
| 4 | 006 → 007 | 先导出视频音轨，再实现内嵌视频按固定时间轴合成；用独立播放器核对画面、声音和时间戳 |
| 5 | 008 / 009 / 010 | 用真实样本分别界定 SmartArt/OLE、高级渲染及旧 PPT 增量写入，形成可验证的实现票 |

复杂脚本、变量字体、CFF / WOFF 解压不在当前字体支持范围。本机替换字体不写入 PPTX。Windows PowerPoint 真机仍按此前要求暂缓。

## 验证与安装包

新环境先执行 `python3 -m pip install --target out/font-glyphs/python -r tooling/font-glyph-requirements.txt`；独立字体 / PDF 读取依赖固定版本，CI 与发布工作流执行同一安装。

本轮 `npm run check`、`npm test`、`npm run build`、`npm run verify` 已依次通过。源码与 dist 矢量 PDF 契约已纳入常规门禁。
