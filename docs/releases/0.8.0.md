# 0.8.0 发布记录

0.8.0 线（`0.8.0-beta.1` 至 `0.8.0`）的发布与验证证据。用户可见的变化见 [CHANGELOG](../../CHANGELOG.md)，当前进度见 [roadmap](../roadmap.md)。本文发布后冻结；`collab` 体积一节由 `npm run verify` 与当前构建比对，包版本前进到下一版前保持与实测一致。

## npm 发布

| 版本 | 日期 | dist-tag | 发布与安装验收 |
|---|---|---|---|
| `0.8.0-beta.1` | 2026-11-04 | `next` | 九包经官方 registry 全新安装，SDK 入口、填充 Schema 与真实 MCP 握手通过；既有八包 `latest` 保持 `0.6.0`，`agent-mcp` 首版 |
| `0.8.0-beta.2` | 2026-11-04 | `next` | 九包经 GitHub OIDC 发布，`@web-ppt/agent-mcp` 的 Trusted Publisher 完成首次成功发布激活；隔离安装发现 MCP 握手仍报告 `beta.1` |
| `0.8.0-beta.3` | 2026-11-04 | `next` | 九包经 GitHub OIDC 发布；匿名下载的实际 SRI、隔离安装、SDK / fill Schema、MCP `beta.3` 握手及十个工具通过，Node 20 / 24 复验 |
| `0.8.0` | 2026-11-06 | `latest` | `0.8.0-beta.3` 转正；MCP 实际安装握手报告 `0.8.0` |

## 门禁

`0.8.0` 转正时四项自动门禁（`check` / `test` / `build` / `verify`）、OOXML 合法性门禁（ECMA-376 XSD 与 Open XML SDK 双通道）与 LibreOffice 外部打开清单全部通过。

Windows PowerPoint 真机验收继续延后，未记为通过；runner 约束见 [powerpoint-runner.md](../engineering/powerpoint-runner.md)。

## 体积口径

`@web-ppt/collab` 发布入口为 12.20KB gzip；排除 peer 的完整测试薄包为 14,333B gzip，两种口径分别核对。
