## 门禁

`0.9.0-beta.1` 发布前：`check`（tsc ×2 + Biome）、全量功能测试与编辑器性能采样、`build`、OOXML 合法性门禁（ECMA-376 XSD 与 Open XML SDK 双通道，148 份产物）与 `verify` 全部通过；本版与 master 的 Biome 重排 / TypeScript 7 / Vite 8.3 工具链升级合并后在同一依赖树上重验。

`0.9.0-beta.2` 发布前：四门禁全绿；OOXML 合法性门禁扩容到 172 份产物（新增新建图表 23 型与图表分析元素固件的保存产物），XSD 与 Open XML SDK 双通道零错误。

Windows PowerPoint 真机验收继续延后，未记为通过；runner 约束见 [powerpoint-runner.md](../engineering/powerpoint-runner.md)。

## 体积口径

`@web-ppt/collab` 发布入口为 11.35KB gzip；排除 peer 的完整测试薄包为 14,367B gzip，两种口径分别核对。
